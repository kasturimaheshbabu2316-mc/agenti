# PMM 3 – Bidding Interface (agenti)

Zero-backend, multi-view real-time quiz auction engine for Pharmaceutics Mastery Matrix 3 (PMM 3).

## Features
- **Team Bidding Terminal (`index.html`)**: Interactive bidding, wallet tracking, question hero, answer submission UI, live feed, and leaderboard.
- **Quiz Master Management (`admin.html`)**: Passcode security gate, question authoring across 8 formats, team ledger management, draft staging and release.
- **Projector & Hall Display (`live.html`)**: High-visibility hall display, live bid ladder, leader highlights, giant countdown timers, solution reveals.
- **Pure Web Standards**: Client-side synchronization via Web Storage API with zero external backend dependencies.
